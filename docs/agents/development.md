# Development and deployment

Use Python 3.11+ and the Node/npm pins in `frontend/.nvmrc` and `package.json`.
`uv sync --frozen --extra test --extra lint --extra codegen` sets up the SDK.
The only Python workspace distribution is `sdk/python` (`kfp`).

The native stack is generated by `samples/argo-native/deploy.py` using
`third_party/argo/VERSION`. It uses Argo, persistent PostgreSQL/archive and S3
artifact storage, and a static Nginx UI/proxy. See the sample README for commands.
The local setup uses development storage credentials and an internal self-signed
Argo certificate; bind port-forwards to loopback, not a public interface.

`_KFP_RUNTIME=true` selects lightweight in-container imports. Runtime images must
contain this checkout's wheel. `Compiler(image_digests=...)` emits content-named
local references; `compile_demo.py` creates and verifies their Docker tags.

Frontend development proxies `/argo/` and `/kubernetes/` to the deployed authenticated
proxy (default `http://127.0.0.1:3003`, override `KFP_NATIVE_PROXY`). It does not run
a Node application backend or manufacture credentials. Use explicit Kubernetes
contexts and restart a port-forward after replacing its target UI pod.
