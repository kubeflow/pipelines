# Triage Labels

This file maps supported triage roles to the actual label strings used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `status/triaged`     | Issue has been explicitly triaged        |
| `needs-info`               | `needs more info`    | Waiting on reporter for more information |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

When a skill mentions a supported role, use the corresponding label string from this table.

Edit the right-hand column to match whatever vocabulary you actually use.
