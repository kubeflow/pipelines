# Contributor Guide

Kubeflow Pipelines is an open source project and welcomes community
contributions. The canonical contribution guidelines live in the repository and
are the source of truth:

- [CONTRIBUTING.md](https://github.com/kubeflow/pipelines/blob/master/CONTRIBUTING.md)
  — how to propose changes, the feature-request and design-review process, coding
  style, and the pull request title convention.
- [Backend development guide](https://github.com/kubeflow/pipelines/blob/master/backend/README.md)
- [Frontend development guide](https://github.com/kubeflow/pipelines/blob/master/frontend/README.md)
- [SDK contribution guidelines](https://github.com/kubeflow/pipelines/blob/master/sdk/CONTRIBUTING.md)

## Sign off your commits

Kubeflow uses the Developer Certificate of Origin
([DCO](https://github.com/apps/dco/)). Sign off every commit with `git commit -s`;
see the [DCO sign-off guide](https://github.com/kubeflow/community/tree/master/dco-signoff-hook#signing-off-commits).

## Get involved

- File bugs and feature requests as [GitHub issues](https://github.com/kubeflow/pipelines/issues).
- Join the discussion on the [kubeflow-discuss](https://groups.google.com/g/kubeflow-discuss)
  Google Group and in the Kubeflow Pipelines community meeting.
- See [Community and Support](../reference/community-and-support.md) for all
  channels.
