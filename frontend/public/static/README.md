# Pipelines artwork

`kubeflow-pipelines.svg` is the unmodified color icon from the [official CNCF artwork repository](https://github.com/cncf/artwork/blob/main/projects/kubeflow-pipelines/icon/color/kubeflow-pipelines-icon-color.svg). It is used by the browser favicon. Logo use follows the [CNCF artwork trademark policy](https://github.com/cncf/artwork/blob/main/LICENSE.md).

`kubeflow-pipelines-small.svg` is a locally adapted sidebar variant for 28px rendering: it retains the blue silhouette and five-node pipeline structure, with thicker white lines and node outlines, a single blue fill, and no arrowheads or dark border. It is not the unmodified official artwork.

The graph canvas omits the optional React Flow watermark via its documented `hideAttribution` option. React Flow's MIT copyright and license ship alongside the other browser dependencies in the build-generated `THIRD_PARTY_NOTICES.txt`; see [frontend third-party notices](../../README.md#third-party-notices).
